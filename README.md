# Karta card flow — prototypes

Static build of the Karta card-flow prototypes (Card flow 1 and Card flow 2),
for viewing on a phone via GitHub Pages.

Open https://bhz-kart.github.io/card-flow/ in Safari → Share → Add to Home
Screen to run it full screen.

Source: `src/prototypes/team/CardFlow1.tsx` / `CardFlow2.tsx` in
bhz-kart/karta-design-system (built with `vite build --mode prototypes --base ./`).

## Preview in Claude

Connect this repository in Claude Code and open the **Preview** panel on the
right: the `prototypes` server from `.claude/launch.json` starts a plain
static server (`python3 -m http.server 5180`) — nothing to install. The
Prototypes list opens; pick Card flow 1 or Card flow 2.
